# InvestDatabase_Project
Разработка DataVault хранилища данных для проекта "Инвесткопилка" абстрактного Банка

Целью разработки является создание отдельного хранилища данных под нужды нового проекта в некотором Банке. Для выполнения этой задачи необходимо:
- Выполнить сбор бизнес-требований от заказчика, информацию об источнике данных
- Разработать концептуальную и логическую модель БД
- Написание ETL-процессов на plpgsql не "перетекания" данных от источника и между слоями хранилища
